Minecraft Data Pack

Door → Trapdoor

One wooden door splits into two trapdoors. Already running on this server — install and play.

Overview

This data pack adds a custom crafting recipe to your server: any wooden door can be crafted into two matching trapdoors at a crafting table. Handy for turning spare doors into something more flexible while building.

🚪
Any Wooden Door ×1
→
🪵
Trapdoors ×2

Supported Woods

Works with all standard wooden doors, for example:

Oak Spruce Birch Jungle Acacia Dark Oak Mangrove Cherry Bamboo Crimson Warped Pale Oak

These are not included:

Iron Door Copper Door

How to Use

  • The pack is already installed on the server and loads automatically on startup.
  • Players need no client-side mods — just join and play.
  • Open a crafting table, put in one wooden door, and the result slot shows two trapdoors.
  • The output always matches the material of the door you put in.
